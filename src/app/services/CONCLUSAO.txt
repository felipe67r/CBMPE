🚀 COMO USAR - QUICK START
──────────────────────────────────────────────────────────────────────────────

1. VERIFICAR DEPENDÊNCIAS
   ✓ Angular 20+
   ✓ Ionic 8+
   ✓ RxJS 7.8+
   ✓ npm packages atualizados

2. IMPORTAR HTTPMODULE (app.module.ts)
   import { HttpClientModule } from '@angular/common/http';
   
   @NgModule({
     imports: [HttpClientModule]
   })

3. USAR EM COMPONENTE
   import { DataService } from './services/data.service';
   
   export class MeuComponente {
     constructor(private dataService: DataService) {}
     
     login() {
       this.dataService
         .login('matricula', 'senha', 'unidade')
         .subscribe(
           response => console.log('Login OK'),
           error => console.error(error.message)
         );
     }
   }

4. TESTAR
   npm test

5. COMPILAR
   ng build

⚠️ OBSERVAÇÕES IMPORTANTES
──────────────────────────────────────────────────────────────────────────────

1. HttpClientModule DEVE estar importado
   → Sem ele, HttpClient não funcionará

2. Backend deve estar rodando em http://localhost:3000
   → Ou alterar API_URL em data.service.ts

3. Usuário persiste em localStorage até logout
   → Isso é esperado para manter sessão

4. Ocorrência é armazenada em sessionStorage
   → Perdida ao fechar o navegador (esperado)

5. Todos os métodos async retornam Observables
   → Use .subscribe() ou async pipe no template

6. Logout é automático em erro 401
   → Melhor prática de segurança

📞 TROUBLESHOOTING RÁPIDO
──────────────────────────────────────────────────────────────────────────────

❌ "Cannot find module '@angular/common/http'"
   ✓ Solução: npm install

❌ "ERR_CONNECTION_REFUSED localhost:3000"
   ✓ Solução: Inicie o backend ou altere API_URL

❌ "HttpClient not provided"
   ✓ Solução: Importe HttpClientModule no app.module.ts

❌ "Usuário desaparece ao recarregar"
   ✓ Solução: Normal se localStorage foi limpo

❌ "Testes falhando"
   ✓ Solução: npm install && npm test

Para mais detalhes: GUIA_INTEGRACAO.md
